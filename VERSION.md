# Las Dos Islas — EFA Country Simulator™ Beta v0.3.9

## Stable milestone

This package contains the bilingual public web build of **Las Dos Islas — EFA Country Simulator™**.

### Included in v0.3.9
- Spanish / English interface
- Level 1 — Fundamentals
- 12-turn economic simulation
- EFA Score™ / 1,000
- Dynamic score sphere: size + color
- Personal best score and comparison
- EFA diagnosis
- Decision log
- Real economic indicators
- End-of-game result card
- Browser persistence through localStorage
