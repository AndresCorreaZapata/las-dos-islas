# Las Dos Islas — EFA Country Simulator™ — V1.0

Propietario conceptual y autor: Andrés Correa Zapata.

## Archivos
- index.html — juego
- manifest.webmanifest — configuración PWA
- sw.js — funcionamiento offline básico
- icon.svg — icono

## Publicación
Crear un repositorio GitHub personal, subir estos archivos y activar GitHub Pages. Después conectar un dominio propio.

## Nota
V1.0 es un simulador experimental: sus relaciones económicas son mecánicas de juego y no un modelo econométrico ni asesoría de política económica.
