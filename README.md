# Las Dos Islas — EFA Country Simulator™

**EFA Country Simulator™ — Beta v0.3.9**

An experimental economic strategy game based on **Estrategias de Flujo Adaptativo (EFA)** by Andrés Correa Zapata.

## Play

Once GitHub Pages is enabled, the game is available at:

`https://andrescorreazapata.github.io/las-dos-islas/`

## Current milestone

**Level 1 — Fundamentals**

The player governs Island A for 12 turns and makes policy decisions affecting productivity, investment, prices, employment, taxation, business freedom and debt.

The final result includes the **EFA Score™ / 1,000**, dynamic score visualization, personal-best comparison and EFA diagnosis.

## Roadmap

- Level 2 — Growth
- Level 3 — Purchasing Power
- Level 4 — Resilience
- Level 5 — EFA Master
- EFA WORLD™ — The Economic Strategy Game

Spanish / English in the current beta. The architecture is intended to support additional languages in future releases.
